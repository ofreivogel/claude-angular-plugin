Dieses Repo ist ein Fork der Angular Skills des Angular Teams

Die Skills verwenden dabei Angular CLI, welches in der Regel in einem NX Workspace nicht zur Verfügung steht.
Dieses Repo hat zwei Funktionen:
- Original Skill als plugin für Claude code bereit zu stellen
- Eine Abgewandelte Variante des angular-developer Skills für nx bereit zu stellen und der Pfad nx.

Orginal Skills sollten nie angepasst werden nur deren Änderungen von Upstream aktualisiert werden.
